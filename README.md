# INET Software Trainee - Cooperative
บันทึกการเรียนรู้ก่อนฝึกสหกิจศึกษาที่บริษัท อินเทอร์เน็ตประเทศไทย จำกัด (มหาชน)

## Week 01 (28 Aug 2026)
**เป้าหมาย:** ศึกษาพื้นฐานของ Vue.js
    
**สิ่งที่ได้เรียนรู้:**
- ศึกษาโครงสร้างการทำงานของ `Vue.js`
- สร้างหน้า UI พื้นฐานด้วย Vue.js (โฟลเดอร์ `Week01`)

## Week 02 (4 Sep 2026)
**เป้าหมาย:** ศึกษาการจัดการข้อมูลด้วย Two-way Data Binding
    
**สิ่งที่ได้เรียนรู้:**
- ทำความเข้าใจและทดลองใช้งาน `v-model`
- สร้างหน้า UI เพื่อรับค่าจากช่อง Input และแสดงผลแบบเรียลไทม์ (โฟลเดอร์ `Week02`)

## Week 03-04 (11-18 Sep 2026)
**เป้าหมาย:** รวบยอดเนื้อหาและปรับโครงสร้างโปรเจกต์หลัก, ศึกษา List Rendering และ Event Handling
    
**สิ่งที่ได้เรียนรู้:**
- ปรับโครงสร้างโปรเจกต์หลัก (Main Project) เพื่อลดการติดตั้งแพ็กเกจซ้ำซ้อน
- ศึกษาและใช้งาน `v-for` สำหรับวนลูปแสดงข้อมูล (Week 03)
- ศึกษาและใช้งาน `@click` ร่วมกับ Methods เพื่อสร้างปฏิสัมพันธ์กับผู้ใช้ (Week 04)
- สร้างมินิโปรเจกต์ To-Do List (โฟลเดอร์ `Week03-04`)

## Week 05 (25 Sep 2026)
**เป้าหมาย:** ประยุกต์ใช้ความรู้ Vue.js สร้าง UI Mockup ระบบบริหารจัดการพัสดุสำหรับหอพัก

**สิ่งที่ได้เรียนรู้:**
- ประยุกต์ใช้ `ref` จัดเก็บข้อมูลซับซ้อนรูปแบบ Array of Objects (เลข Tracking, ชื่อผู้รับ, สถานะ)
- ใช้ `v-for` ร่วมกับโครงสร้างตาราง HTML (`<table>`) ในการแสดงผลข้อมูลรายการพัสดุ
- พัฒนาระบบค้นหาและกรองข้อมูลพัสดุแบบเรียลไทม์ด้วย `computed` property
- พัฒนาฟังก์ชันเพิ่มรายการพัสดุใหม่ และฟังก์ชันอัปเดตสถานะพัสดุ ("รอรับ" -> "รับแล้ว")
- สร้างมินิโปรเจกต์ Mockup ระบบพัสดุหอพัก (โฟลเดอร์ `Week05`)

## Week 06 (2 Oct 2026)
**เป้าหมาย:** ศึกษาและออกแบบโครงสร้างฐานข้อมูลพัสดุด้วย MySQL

**สิ่งที่ได้เรียนรู้:**
- ศึกษาการจำลองเซิร์ฟเวอร์ฐานข้อมูลในเครื่อง (Localhost) ด้วย XAMPP และ phpMyAdmin
- สร้างฐานข้อมูล `dorm_parcel_db` และตาราง `parcels` ด้วยคำสั่ง SQL
- กำหนดชนิดข้อมูล (Data Types) ที่เหมาะสม เช่น `VARCHAR`, `ENUM`, `TIMESTAMP`
- ทดลองเพิ่มข้อมูลจำลอง (Mock Data) ลงในตารางด้วยคำสั่ง `INSERT INTO`
- จัดเก็บสคริปต์โครงสร้างฐานข้อมูล (โฟลเดอร์ `Week06/database.sql`)

## Week07 (9 Oct 2026)
**เป้าหมาย:** ศึกษาการเชื่อมต่อฐานข้อมูล MySQL ด้วยภาษา Go และสร้าง API สำหรับระบบบริหารจัดการพัสดุสำหรับหอพัก

**สิ่งที่ได้เรียนรู้:**
- ศึกษาการเชื่อมต่อฐานข้อมูล MySQL ด้วยภาษา Go
- สร้าง API สำหรับระบบบริหารจัดการพัสดุสำหรับหอพัก (โฟลเดอร์ `Week07`)

## Week 08 (9 Oct 2026)
**เป้าหมาย:** ประกอบร่างโปรเจกต์ (Integration) เชื่อมต่อหน้าบ้าน Vue.js เข้ากับหลังบ้าน Go (Fiber) และฐานข้อมูล MySQL เพื่อพัฒนาเป็นระบบ Full-Stack ฉบับสมบูรณ์

**สิ่งที่ได้เรียนรู้:**
- ศึกษาและประยุกต์ใช้คำสั่ง `fetch` ใน JavaScript เพื่อรับ-ส่งข้อมูลกับ Backend API (HTTP GET, POST, PUT)
- ดึงข้อมูลรายการพัสดุจากฐานข้อมูลมาแสดงผลบนหน้าเว็บแบบเรียลไทม์ด้วย `onMounted`
- พัฒนาฟังก์ชันเพิ่มพัสดุใหม่ (POST) และอัปเดตสถานะพัสดุ (PUT) โดยบันทึกข้อมูลลงฐานข้อมูล MySQL จริงอย่างถาวร
- ทำความเข้าใจกระบวนการทำงานแบบ Full-Stack และการบริหารจัดการเซิร์ฟเวอร์ด้วย Multi-terminal (รัน Backend Go Fiber และ Frontend Vite พร้อมกัน)
- รวมร่างมินิโปรเจกต์ระบบบริหารจัดการพัสดุหอพัก Full-Stack ฉบับสมบูรณ์ (โฟลเดอร์ `Week08`)

## Week 09 (16 Oct 2026)
**เป้าหมาย:** เติมเต็มระบบให้สมบูรณ์ด้วยการทำ CRUD Operations ให้ครบถ้วน (เพิ่มฟังก์ชันลบข้อมูล)

**สิ่งที่ได้เรียนรู้:**
-  พัฒนา API ฝั่ง Go Fiber สำหรับรับคำสั่ง `DELETE` และรันคำสั่ง SQL `DELETE FROM` เพื่อลบข้อมูลใน MySQL
-  ประยุกต์ใช้คำสั่ง `fetch` รูปแบบ `method: 'DELETE'` ในการส่ง Request จากหน้าเว็บ
-  เพิ่มระบบแจ้งเตือนยืนยัน (Confirmation Dialog) ด้วย `confirm()` ใน JavaScript ก่อนทำคำสั่งลบเพื่อป้องกันผู้ใช้กดผิดพลาด (UX Improvement)
-  ระบบบริหารจัดการพัสดุตอนนี้สามารถทำ CRUD (Create, Read, Update, Delete) ได้ครบสมบูรณ์ 100%
